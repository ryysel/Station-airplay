# Station AirPlay

Station-airplay позволяет слушать звук с iPhone, iPad или Mac на Яндекс Станции через AirPlay 2. Плагин работает на самой колонке под управлением [Luna](https://github.com/nyakokitsu/luna), которую устанавливает менеджер пакетов YAM. Он направляет музыку в общий микшер станции, поэтому Алиса может отвечать во время воспроизведения.

```text
Устройство Apple → AirPlay 2 → плагин Station-airplay → Яндекс Станция
                              запуск через Luna       установка через YAM
```

Поток принимает и декодирует **Shairport Sync**. Программа на Go запускает приёмник и связывает его с громкостью, голосовыми командами и индикацией станции. Передача видео и повтор экрана в проекте не реализованы.

## Что нужно

| Требование | Зачем |
|---|---|
| Подготовленная станция с поддержкой YAM и доступом по SSH | Плагин устанавливается в Linux на колонке; обычного приложения «Дом с Алисой» для установки недостаточно. |
| YAM **0.2.5+** для установки из реестра v2 | Эта версия понимает `postinstall`: после распаковки пакет может включить плагин в Luna. |
| Luna | Запускает плагин и предоставляет API устройства, громкости и речи. Пакет из реестра рекомендует нужную версию Luna. |
| iPhone, iPad или Mac с AirPlay в той же локальной сети | Устройство должно найти станцию и передать ей звук. Гостевая сеть с изоляцией клиентов этому мешает. |
| Свободные порты приёмника | Второй AirPlay-приёмник не сможет занять те же порты. [Сетевые требования](docs/INSTALLATION.md#сеть). |

Go и компилятор C для готового пакета не нужны. Для сборки Go-программы нужны **Go 1.23+** и Linux или WSL; для упаковки — **Python 3.8+**. Библиотеки и инструменты полной сборки перечислены в [руководстве по сборке](source/BUILD.md).

## Поддерживаемые модели

Таблицы описывают пакеты YAM v2 версии **2.0.7**. «Только аудио» означает, что поток и Алиса работают рядом, но голосовое управление AirPlay, двусторонняя громкость и кнопка Алисы не включены. Сама Алиса остаётся доступной.

| Станция | YAM model ID | Режим пакета | На чём проверяли 2.0.x |
|---|---|---|---|
| Станция 2 | `yandexstation_2` | Аудио и управление | Живая колонка и эмулятор |
| Мини 2 | `yandexmini_2` | Аудио и управление | Живая колонка и эмулятор |
| Лайт 2 | `plum`, `yandexplum` | Аудио и управление | Живые колонки с часами и без; эмулятор |
| Лайт | `yandexmicro` | Аудио и управление (по профилю) | Эмулятор |
| Мини | `yandexmini`, в коде также `YandexStationMini` | Только аудио | Эмулятор |
| Миди | `yandexmidi` | Только аудио | Эмулятор |
| Станция 3 | `yandexstation_3` | Только аудио | Эмулятор |
| Станция Стрит | `mango` | Аудио и управление (по профилю) | Только эмулятор; реальное воспроизведение и физические светодиоды не проверены |
| Мини 3 | `bergamot` | Только аудио | Эмулятор |
| Мини 3 Про | `yandexmini_3_pro` | Есть профиль в исходниках; нет пакета v2 | Текущая поставка v2 не проверена |

Что именно включает пакет на каждой модели:

| Модель | `voice` | `native_volume` | `ducking` | `leds` | `native_player` | `alice_button` |
|---|---|---|---|---|---|---|
| Станция 2 | да | да | да | да | авто* | авто* |
| Мини 2 | да | да | да | да | авто* | авто* |
| Лайт 2 | да | да | да | да | авто* | авто* |
| Лайт | да | да | да | да | авто* | нет |
| Мини | нет | нет | нет | нет | нет | нет |
| Миди | нет | нет | нет | нет | нет | нет |
| Станция 3 | нет | нет | нет | нет | нет | нет |
| Станция Стрит | да | нет | да | да | нет | нет |
| Мини 3 | нет | нет | нет | нет | нет | нет |
| Мини 3 Про | — | — | — | — | — | — |

«Нет» у аудио-моделей означает, что пакет не передаёт им конфиг управления; сама Алиса продолжает работать. `авто*` — лаунчер при первом создании конфига включает `native_player`, если найден `/system/vendor/quasar/q`; `alice_button` дополнительно требует модель `yandexmini_2`, `yandexplum` или `yandexstation_2` и найденную клавиатуру. Если CLI или кнопка не найдены, runtime оставляет функцию выключенной и пишет причину в лог, поэтому на эмуляторах и в аудио-режиме эти поля остаются `false`. `mango` получает голос, ducking и индикацию, но не трогает громкость Quasar и не перехватывает кнопку Алисы.

Эмулятор подтверждает установку, запуск, автозапуск и кадры, которые приёмник отправляет в индикацию. Он не подтверждает звук, микрофон или физические светодиоды. Начиная с 2.0.5 `yam/luna >=0.2.20` — зависимость пакета. Реестр хранит зависимости на версию целиком, поэтому у `orion`, `yandexmidi`, `yandexplum` и `mango` она разрешается только если подходящая Luna уже установлена; свежая установка на этих платформах ждёт релиза Luna с их артефактами. В 2.0.7 `mango` и `orion` уже имеют артефакты Luna 0.2.22; `yandexmidi` и `yandexplum` разрешаются через алиасы после релиза YAM с их поддержкой. Результаты более ранних версий и аудиопрофили собраны в [SHARED_MODELS.md](docs/SHARED_MODELS.md).

`cucumber` и `orion` встречаются как целевые платформы пакетов Миди и Станции 3. Это не дополнительные модели для подстановки в конфигурацию. Не меняйте model ID ради установки чужого пакета.

## Установка

На устройстве или компьютере с настроенным YAM добавьте реестр один раз:

```sh
yam registry add official https://repo.yse.wtf/v2 \
  --key ed25519:5Rz8F47uftWVU5kLgWYhprkEZ4rpP2kecUge/a7KQas=
```

Затем установите пакет для выбранной в YAM станции:

```sh
yam install airplay/airplay-luna
```

YAM распакует плагин. Luna пакет только рекомендует и сам её не ставит: если её нет, выполните `yam install yam/luna`. После установки фоновый процесс дождётся API Luna и включит плагин. Когда приёмник запустится и опубликует себя в сети, станция появится в меню AirPlay.

В интерфейсе Luna плагин `airplay.airplay-luna` должен быть включён и иметь состояние `running`. Фоновый процесс повторяет включение около 20 минут, если Luna или плагин ещё не готовы. После этого плагин можно включить вручную.

[Установка из файла, проверка портов и старый формат `.yap`](docs/INSTALLATION.md).

## Как слушать

1. Подключите устройство Apple и станцию к одной локальной сети.
2. На iPhone или iPad включите музыку. Откройте AirPlay в проигрывателе или в карточке воспроизведения Пункта управления и выберите станцию.
3. На Mac выберите станцию в **Пункт управления → Звук**. Для нескольких колонок используйте меню AirPlay в приложении «Музыка».
4. Дождитесь подключения. Станция станет выбранным выходом, а звук пойдёт через её динамики.

Сопряжение выполняет Shairport Sync при подключении. В штатной конфигурации вводить PIN или добавлять станцию в приложение «Дом» не требуется.

На моделях с управлением можно сказать «Алиса, поставь на паузу» или «Алиса, следующий трек». Luna передаст распознанную команду плагину, а тот отправит её плееру на телефоне или Mac. Во время обычного ответа Алисы музыка приглушается, если включён `ducking`.

## Настройка

Пакет v2 хранит настройки в `$LUNA_PLUGIN_STATE/airplay-controls.json`. Скрипт запуска (launcher) создаёт файл при первом запуске и сохраняет последующие правки. Возможности модели определяют, какие настройки работают.

| Поле | Что меняет | Обычный первый запуск пакета v2 |
|---|---|---|
| `voice` | Голосовые команды плееру отправителя | `true` на моделях с управлением |
| `native_volume` | Связывает громкость телефона и станции | `true` на моделях с управлением, кроме `mango` |
| `ducking` | Приглушает поток, пока Алиса слушает и отвечает | `true` |
| `leds`, `led_level` | Включает индикацию и задаёт яркость | `true`, `200`, если модель поддерживает индикацию |
| `native_player` | Удерживает штатный плеер на паузе, чтобы после команды он не играл одновременно с AirPlay | Лаунчер включает при первом запуске, если найден `/system/vendor/quasar/q`; иначе `false` |
| `alice_button` | Переключает паузу AirPlay коротким нажатием кнопки Алисы | Лаунчер включает на `yandexmini_2`, `yandexplum`, `yandexstation_2` при наличии Quasar CLI и найденной кнопки; иначе `false` |

[Полный справочник: значения по умолчанию, ограничения JSON, флаги и перезапуск](docs/CONFIGURATION.md).

## Сборка

На Linux/WSL из корня репозитория:

```sh
cd source
go test ./...
go vet ./...
GOOS=linux GOARCH=arm GOARM=7 CGO_ENABLED=0 \
  go build -buildvcs=false -trimpath -ldflags='-s -w' \
  -o ../bin/station-airplay .
cd ..
python3 scripts/package.py
```

`go build` заменяет только Go-супервизор в `bin/station-airplay`. Упаковщик берёт его вместе с имеющимися `bin/`, `lib/`, конфигурацией и лицензиями и создаёт `dist/station-airplay-2.0.5.yap`. Он не пересобирает Shairport Sync и не создаёт `.yampkg`.

Makefile в репозитории нет. [Полная инструкция](source/BUILD.md) объясняет сжатие UPX, сборку сторонних компонентов и проверки пакета.

## Если что-то не работает

| Когда | Что проверить сначала |
|---|---|
| Станции нет в меню AirPlay | Состояние плагина в Luna, затем mDNS и изоляцию клиентов Wi-Fi |
| Станция видна, но подключение не завершается | Лог приёмника, TCP-порт и сетевые порты сеанса |
| Музыка играет, команды Алисы не действуют | Режим модели, `voice` и возможности `/media` в Luna |
| После правки настроек плагин не запускается | Ошибку JSON в логе; неизвестные поля останавливают запуск |

Для каждого случая есть цепочка «условие → причина → исправление» в [диагностике и FAQ](docs/TROUBLESHOOTING.md). [Проверка на своей колонке](docs/CHECK_ON_YOUR_SPEAKER.md) помогает проверить путь от установки до повторного подключения.
